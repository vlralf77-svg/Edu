# 내 PC 에 설치해서 쓰기 (서버 필요 없음)

에이전트는 **내 컴퓨터에서 돌아가는 프로그램**입니다. 별도 서버나 월 요금 호스팅이 필요 없습니다.
화면은 내 PC 의 브라우저 창에서 열리며(주소 `localhost`), 외부에서는 접속할 수 없습니다.

## 1. 내려받기

1. GitHub 저장소 페이지 → 브랜치를 `ccr-b9583e07-cqmtum` 으로 선택 → **Code ▸ Download ZIP**
2. 압축을 풀고 안의 `trend-shorts-agent` 폴더를 원하는 곳(예: `문서`)에 둡니다.
   - Windows 는 경로에 한글이 없는 곳을 권장합니다 (예: `C:\TrendShorts`).

## 2. 설치 (처음 한 번)

| PC | 할 일 |
|---|---|
| **Windows 10/11** | `install_windows.bat` 더블클릭 → 끝나면 바탕화면에 **Trend Shorts Agent** 아이콘 생성 |
| **Mac** | [Homebrew](https://brew.sh) 설치 후 `install_mac.command` 더블클릭 (막히면 우클릭 ▸ 열기) |
| **Linux** | 터미널에서 `./install_linux.sh` |

설치 스크립트가 자동으로 해 주는 것: 파이썬 3.12, 필요한 부품, FFmpeg(영상 합성), 설정 파일 준비.
배경음악용 fluidsynth 는 없어도 됩니다 (내장 신시사이저로 자동 대체).

> Windows 에서 "PC 보호" 파란 창이 뜨면 **추가 정보 ▸ 실행** 을 누르세요.

## 3. 실행

- Windows: 바탕화면 **Trend Shorts Agent** 아이콘 / Mac: `start_mac.command` / Linux: `./start_linux.sh`
- 검은 창(콘솔)이 뜨고 브라우저에 제어판이 열립니다. **검은 창을 닫으면 제어판이 꺼집니다.**

## 4. 처음 설정 (제어판 메뉴)

1. **🩺 점검** — 빠진 항목 확인
2. **⚙️ 설정 ▸ API 키** — 발급받은 키 입력 후 [키 저장]
   - Claude(유료), YouTube Data API(무료), Pexels(무료), Pixabay(선택, 무료), ElevenLabs(음성)
3. **⚙️ 설정 ▸ 동작 설정** — 하루 주제 수, 비용 상한, 모델, 실행 시각, ElevenLabs 보이스 ID → [설정 저장]
4. **🩺 점검 ▸ YouTube 수집만 시험해 보기** — 비용 없이 키가 맞는지 확인
5. **🏠 홈 ▸ 처음이라면: 샘플 영상 만들어 보기** — 키 없이 제작 과정 시험

## 5. 매일 쓰는 흐름

1. **🏠 홈 ▸ ① 오늘 트렌드 분석 시작** (또는 자동 실행)
2. **✅ 후보 검토** 에서 대본을 읽고 승인/보류/반려, 필요하면 문장 수정
3. **🏠 홈 ▸ ③ 승인된 영상 제작**
4. **🎬 만든 영상** 에서 미리보기 → [영상 저장] → 제목·설명란 복사해서 YouTube 에 업로드
   (업로드 시 '변경되거나 합성된 콘텐츠' = 예)

## 6. 자동 실행 (선택)

**⏰ 자동 실행 ▸ 자동 실행 등록** 을 누르면 이 PC 의 예약 작업에 등록됩니다.
- Windows: 작업 스케줄러에 `TrendShortsAgent` 등록 + 로그인 시 보충 실행
- Mac/Linux: crontab 등록 + 부팅 시 보충 실행
- PC 가 꺼져 있던 날은 다음에 켜고 로그인할 때 자동으로 한 번 실행됩니다 (하루 1회만).
- 기본(사람 승인 모드)에서는 **분석·후보 작성까지만 자동**이고, 영상 제작은 검토 후 버튼으로 합니다.
- 제어판 창을 닫아 둬도 예약 실행은 동작합니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 점검에서 FFmpeg ❌ | 설치 직후라면 PC 를 재시작하거나 새 창으로 다시 실행. 그래도 안 되면 PowerShell 에서 `winget install Gyan.FFmpeg` |
| 한글이 □□ 로 나옴 | `assets/fonts` 폴더에 Pretendard 또는 Noto Sans KR `.ttf/.otf` 파일 넣기 |
| 비용 상한 초과로 중단 | 설정에서 상한을 올리거나 하루 주제 수를 줄이기 |
| 작업이 실패함 | 홈/점검 화면의 **작업 로그** 또는 `data/runs/날짜/run.log` 확인 |
